# Bujji Ganesh Youth Festival Website

Official website for **Bujji Ganesh Youth - SRP Committee Kurrollu** Ganesh Chaturthi celebrations.

## 🚀 How to Run

**Double-click:** \RUN-WEBSITE.bat\

Then:
1. Wait 10-15 seconds for server to start
2. Look for: \Local: http://localhost:5173/\
3. Open that URL in your browser

## ✨ Features

- 🪙 **Coin Flip Animation** - Logo spinning in 3D on page load
- 🎨 **Bilingual** - English & Telugu support
- 📱 **Responsive** - Works on mobile, tablet, desktop
- 🎊 **Beautiful Design** - Saffron, maroon, cream, gold theme

## 🛠️ Tech Stack

- React 19
- TanStack Start (Router + Framework)
- Tailwind CSS 4
- TypeScript
- Vite 8
