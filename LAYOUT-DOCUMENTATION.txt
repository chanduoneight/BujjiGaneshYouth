BILINGUAL SYSTEM
================================================================

Languages: English (en) & Telugu (te)

Hook: useLang()
Functions:
- b(object): Get bilingual text from data
  Example: b(festival.festivalName)

- t(key): Get UI string from dictionary
  Example: t("home"), t("schedule")

- lang: Current language ("en" or "te")
- setLang(lang): Change language

Language Toggle: In navbar (top right)
